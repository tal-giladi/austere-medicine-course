# Module 3 quiz: Airway and chest beyond EMT

This quiz has 10 scenario questions on everything in Module 3: airway positioning and suction, the nasopharyngeal airway and BVM targets, recognising tension pneumothorax, needle decompression, finger thoracostomy, surgical cricothyroidotomy, and oxygen and pulse oximetry. Each question is a field decision, not a definition. The pass mark is 70%.

Before you start, make sure you have run the module scenario (needle decompression on ribs, cric on a larynx and the airway decision drill) in lesson 03.7 at least once.
