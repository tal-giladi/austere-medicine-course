# Module 2 quiz: Bleeding beyond EMT

This quiz has 10 scenario questions on everything in Module 2: choosing a hemostatic dressing, junctional, head and neck bleeding, tourniquet reassessment, conversion and removal, long tourniquet times, and pelvic binders. Each question is a field decision, not a definition. The pass mark is 70%.

Before you start, make sure you have run the module scenario (the full tourniquet lifecycle drill) in lesson 02.6 at least once.

- Exposing, repositioning, second tourniquet and distal pulse: [02.3 · Tourniquet reassessment](../lessons/module-02/lesson-03.md)
- Conversion criteria, the 2-hour and 6-hour rules and the step order: [02.4 · Tourniquet conversion and removal](../lessons/module-02/lesson-04.md)
