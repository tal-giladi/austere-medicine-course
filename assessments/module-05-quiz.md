# Module 5 quiz: War injuries

This quiz has 10 scenario questions on everything in Module 5: blast injury, head injury, eye injuries, burns and oral burn resuscitation, abdominal wounds and evisceration, fractures for long transport, hypothermia prevention, and children in trauma. Each question is a field decision, not a definition. The pass mark is 70%.

Before you start, make sure you have run the module scenario (the drone strike with four casualties) in lesson 05.8 at least once.
